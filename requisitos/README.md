# Requisitos de Gestão de Serviços

Os requisitos funcionais são descritos em [requisitos-funcionais.md](requisitos-funcionais.md), no formato “Como ..., gostaria de ..., para que ...”. Incluem os dados necessários para compreender cada função; entradas de exemplo, validações detalhadas, alternativas e falhas ficam nos [cenários](../bvapp/servicos/tests/cenarios/).

RF001 a RF010 são identificadores locais desta documentação do BVapp. Não correspondem aos RF do exemplo de produtos e garantias, nem substituem IDs de work packages. O vínculo com as nove features e os 76 CA está na [rastreabilidade](../docs/rastreabilidade.md).
